## 📖 Overview

**TradeVision** is a Jupyter notebook (`Stock_market.ipynb`) analyzing and forecasting stock
prices for Google, Microsoft, IBM, and Amazon (2006–2018), with Plotly visualizations.

## 🏗️ Project Layout

```
TradeVision/
├── Stock_market.ipynb        # Main analysis & forecasting notebook
├── *_2006-01-01_to_2018-01-01.csv   # Per-ticker historical price data
└── *.png, *.jpg                        # Exported chart snapshots
```


## ⚡ Setup & Run

### 🪟 Windows / 🍎 macOS / 🐧 Linux
```bash
git clone https://github.com/AfnanSharif/TradeVision.git
cd TradeVision

python -m venv venv
# Windows: venv\Scripts\activate | macOS/Linux: source venv/bin/activate
pip install jupyter pandas numpy matplotlib plotly scikit-learn

jupyter notebook Stock_market.ipynb
```
